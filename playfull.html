Playfull

Thư viện khách quản lý WebSocket, phòng chơi và đồng bộ nước đi. Game nạp file này qua playfull.js. 

const pf = new Playfull();
await pf.connect();
pf.on("state", (msg) => render(msg.state));
pf.create("An");
pf.join("K7P2", "Bình");
pf.move({ x: 0, y: 2 }, { x: 0, y: 1 });

Sự kiện

  • open / close / error
  • hello rooms danh sách phòng chờ
  • joined ghế A hoặc B
  • state bàn cờ do server gửi
  • gameover lý do thắng
  • left đã rời phòng
