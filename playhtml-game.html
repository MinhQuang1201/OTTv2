PlayHTML game adapter

playhtml-game-client.js does not open a second connection or store game state in PlayHTML data primitives.

Bootstrap unavailable by default: this page only connects when a verified public PlayHTML initializer, HTTPS control endpoint, and public custom-message channel are explicitly configured.

The browser calls the HTTPS control plane before initializing the game room. It never accepts a ticket in the URL or page data, and it never opens a raw WebSocket or PartySocket.
