Các test theo yêu cầu P3 trong kế hoạch (`tests/bot-cup-submissions.test.js`, `tests/bot-cup-kit.test.js`):

- File > 200 KB (413), file nhị phân, sai mã hóa, sai đuôi (`.txt`, `.cpp`, `.py` trống tên), file rỗng: đều bị từ chối, không ghi gì vào D1.
- Đúng 200 KB và tiếng Việt UTF-8: nhận.
- Lỗi cú pháp (`node --check` / `py_compile`): `judge.mjs` từ chối trước khi chơi. Trên máy chấm, bước này là build trong
  container (`container-executor.mjs`, đã có) và chạy ở P4; Worker không chạy được Python/Node.
- Đổi tên biến, comment, docstring, định dạng, hằng số → cùng hash chuẩn hóa → tạo cờ với đội gốc; bot khác không bị cờ.
  Nộp nguyên `bots/sentinel.mjs` (chỉ đổi chữ trong comment) và template starter kit → cờ với file tham chiếu.
- Đổi Bản thi đấu sau khóa code → 409 `code_frozen`; nộp sau khóa code → 409 `code_frozen`.
- 10 lần/ngày theo giờ Việt Nam, đặt lại đúng 00:00 UTC+7; 200 phiên bản; cùng file hai lần → 409 kèm số phiên bản cũ.
- Đội khác đọc, tải hay chọn bài của mình → 404 (IDOR). Trigger D1 chặn sửa SHA và xoá bài nộp.
- `judge.mjs`: template Python và JS chơi hợp lệ với house bot; bot in rác ra stdout thua vì sai giao thức và trọng tài in
  stderr cuối của bot; bản đóng gói chạy ở thư mục ngoài repo chỉ với Node.

## 4. Trình duyệt (local: `bot-cup:api:dev` + `dev:web`, Chromium/Playwright)

Đăng ký đội cá nhân → OTP từ outbox → trang đội → nộp `bot.py`, `bot.mjs` → nộp trùng (báo "Bản này giống hệt…") → chọn
phiên bản 1 làm Bản thi đấu. 390 px sáng và 1366 px tối, không lỗi JS. Lần chạy đầu ở 390 px **tràn ngang 437 px** do ô chọn
file; đã sửa (`.fileField` co giãn, input `width: 100%`), chạy lại `scrollWidth = 390`. Dòng "việc cần làm" trên thẻ đội cũng
được sửa: hết báo "Nộp bài mở từ …" khi đã mở.

## 5. Quyết định và phát hiện

- **Bản thi đấu chọn được khi `checking`**: Worker không kiểm tra cú pháp; tới P4 runner mới chuyển sang `ready` /
  `build_failed` / `smoke_failed`. Bản lỗi tự mất tư cách (Bản thi đấu quay về bản hợp lệ mới nhất). Lúc khóa code (P7) chỉ
  niêm phong bản `ready`.
- JS luôn chạy như ES module (`bot.mjs` trong container), kể cả file `.js`; ghi trong GUIDE và trên trang nộp bài.
- Byte gốc lưu ở bảng riêng theo SHA-256 (đúng "BLOB khóa theo sha256" §6.2), runner P4 tải theo SHA.
- **House bot `hard` (ai.js) không tự canh giờ**: trong ván dài (~330 nước) nó hết quỹ 30 s và thua (thấy khi chạy `judge.mjs`).
  P5 phải cho house bot canh giờ hoặc không trừ quỹ của house bot.
- Phát kit cho sinh viên: hiện là `npm run bot-cup:kit` (thư mục `var/bot-cup/kit/`). Gắn link tải trên trang giải để ở P5.
